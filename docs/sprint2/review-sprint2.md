## Усунені недоліки комплекту

- Усунуто застарілий ризик про іншу ротацію С2: статут і поточні ролі вже узгоджено.
- Розмежовано 23 дефекти й редакційне RD-16; підсумок більше не залежить від спірного дублювання GUI/F.
- Заповнено аркуші документальної перевірки й додано докази; прибрано порожні результати підготовчих форм.
- Відокремлено завершені документи від зовнішніх погоджень та особистих оцінок.
- Підготовлено навігацію з кореневого README для здачі одним посиланням на репозиторій.

## Пояснення до здачі

Приклад очевидного дефекту — RD-05: у GUI-40 пропущено Phone з F-60. Спірний рядок — RD-16: вимоги GUI і F можуть описувати один екран, тому його не враховано у нормативі. Критичне для наступних тестів протиріччя — RD-10: 5 днів у F-110 проти 7 у BL-60; запропоновано 7, остаточне рішення Q-09 належить замовнику.

План насамперед перевіряє бронювання, ціну, інтервали, доступ і подвійне резервування. Сезонні правила перевіряються в Java-модулі, ціна demo — окремо у фунтах. Контрольні розрахунки 2990,00 / 8541,00 / 149,51 / 11,56 перевірено незалежним обчисленням, а не запуском модуля.

Для формату здачі репозиторієм ця записка замінює сценарій усного представлення. Усне Demo, прийняття викладачем і прогони тестів не позначено проведеними.
