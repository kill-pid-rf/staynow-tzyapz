# Анонімна форма peer review спринта 2

**Команда:** sudo rm -RF. **Продукт:** СтейНау. **Спринт:** 2.

Кожен учасник заповнює власну копію індивідуально, оцінює лише інших двох учасників і передає викладачу приватно. Ім’я автора форми не зазначається. Заповнені оцінки не комітяться до публічного репозиторію. Наведений бланк не означає, що форму вже подано.

Шкала: 5 — зразково; 4 — добре; 3 — прийнятно; 2 — помітні проблеми; 1 — внеску практично не було. Оцінюються підтверджені факти, а не призначена роль.

| Учасник якого оцінюють | Внесок 1–5 | Вчасність 1–5 | Якість 1–5 | Комунікація 1–5 | Коментар із прикладом |
|---|---|---|---|---|---|
| Панасенко Антон | | | | | |
| Копєйка Максим | | | | | |
| Мозговой Артем | | | | | |

Власний рядок не заповнюється. Внесок звіряють із задачами й незалежним аудитом, вчасність — із внутрішніми строками, якість — із результатом рецензії, комунікацію — із реальною участю в обговореннях. Загальна оцінка або коефіцієнт автоматично не розраховуються.
