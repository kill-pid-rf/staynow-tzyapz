# Спринт 2 — Аудит вимог і стратегія тестування СтейНау

**Команда:** sudo rm -RF. **Продукт:** П4 СтейНау (staynow). **Дата підсумкового оформлення:** 27.11.2026.

Досьє якості v2 підготовлено для перевірки викладачем. Матеріали містять 23 підтверджені дефекти вимог та одне редакційне зауваження, SRS 1.1 із журналом 24 правок, план 7 рівнів і 21 застосовного типу із 24 розглянутих.

## Статус і межі результату

Артефакти та документальна рецензія завершені. Матеріали опрацьовано за дорученням команди зі збереженням відповідальних за ролями. ПІБ у таблицях означають відповідальність за артефакт. Особисте незалежне виконання кожним учасником і його підпис цим документом не засвідчуються.

Q-01–Q-19 залишено на розгляд замовника з конкретними запропонованими значеннями: це передбачений §4.8 методички результат аудиту, а не отримане погодження. SRS 1.1 до цих рішень є редакцією для розгляду. Фактичні години не надано. Особисті оцінки peer-review та їх приватне подання не підтверджено.

Retro оформлено письмовим розбором. Усне Demo, особисті підписи та виконання тестів продукту не заявляються. Код Java-модуля та локальний стенд потрібні для наступних прогонів, а не для підміни документального аудиту С2.
