# Спринт 2 Аудит вимог і стратегія тестування СтейНау

**Команда:** sudo rm -RF. **Продукт:** П4 СтейНау (staynow). **Дата підготовки:** 27.11.2026.

Досьє якості v2 містить документальний аудит SRS 1.0, виправлену редакцію SRS 1.1 і стратегію тестування. Підготовлено 24 зауваження — по 4 на кожний критерій; план охоплює 7 рівнів і 21 застосовний тип із 24 розглянутих. Норматив для трьох учасників: ≥12 дефектів, ≥2 на критерій, 7 рівнів і ≥9 застосовних типів.

## Стан перед завершенням спринта

Тексти та таблиці підготовлено до рецензії. Потрібно підтвердити персональних авторів знахідок за незалежними аркушами, рішення щодо спірних рядків і Q-01–Q-19, фактичні години, проведення Retro та приватне подання peer-review. Ці події й результати тестів застосунку не заявлені виконаними. Значення у «Відповідальний» означає призначення перевірки, а не автоматичне авторство знахідки.

План призначений для майбутніх прогонів: звичайні UI-сценарії — на demo з власними записами; навантаження, активна перевірка безпеки, гонки й перезапуски — на ізольованому стенді. Модуль Java та інструкції локального стенда треба отримати до відповідних перевірок.
