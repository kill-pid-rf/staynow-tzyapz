## 3. Рецензування беклогу
| Критерій | Результат перевірки |
|---|---|
| Кількість User Stories | 12, норматив виконано |
| Унікальні ідентифікатори | US-01–US-12, дублікати відсутні |
| Наявність ролі, бажання та мети | Виконано для всіх 12 історій |
| Наявність пріоритетів | High, Medium |

## 5. Підсумок

Підготовлено BPMN-моделі процесів бронювання номера,
заселення і виселення гостей, а також беклог вимог
до нової функції продукту «СтейНау».

Під час роботи виправлено структуру розміщення
BPMN-файлів у репозиторії GitHub та усунено дефект
відображення підпроцесу «Оформити бронювання».
Обидві BPMN-моделі відкрито та візуально перевірено
у редакторі bpmn.io.
Перевірено 12 User Stories та підтверджено
покриття всіх шести очікувань замовника.
