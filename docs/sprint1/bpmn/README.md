## 2. Як відкрити моделі

1. Завантажити необхідний файл формату `.bpmn`.
2. Відкрити редактор [bpmn.io Modeler](https://demo.bpmn.io/).
3. Натиснути Open file та обрати завантажений файл.
4. Переглянути пули, доріжки, події, задачі та потоки.
5. Для перегляду внутрішніх елементів підпроцесу «Оформити бронювання» відкрити його детальну діаграму.
6. За потреби відредагувати модель та зберегти оновлений BPMN-файл.

## 3. Використані елементи BPMN

- Початкові, проміжні та кінцеві події.
- Задачі та згорнутий підпроцес.
- XOR — виключний шлюз за даними.
- Event-based gateway — шлюз за подіями.
- AND — паралельний шлюз.
- Пули та доріжки учасників.
- Потоки управління та повідомлень.
- Об'єкти даних, асоціації та текстові анотації.
