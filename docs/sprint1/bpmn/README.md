## Як відкрити

1. Відкрити demo.bpmn.io, завантажити локальний `.bpmn` через Open file.
2. Перевірити пули, доріжки, потоки, підписи та підпроцес. Деталі згорнутого підпроцесу «Оформити бронювання» описані у product.md та вкладені в XML.
3. За потреби відредагувати, зберегти `.bpmn` та експортувати PNG/PDF (з SVG редактора можна надрукувати PDF). Якщо замінили PNG на PDF, оновити посилання в документах.
4. Зберігати вихідний файл і зображення разом; після зміни моделі оновити таблицю елементів і review.md.

Позначення: коло — подія, подвійне коло — проміжна, товстий контур — кінцева; ромб × — XOR за даними, ромб з подвійним колом і п'ятикутником — XOR за подіями, ромб + — AND; задача з + — згорнутий підпроцес. Суцільні стрілки — sequence flow, штрихові з кружком — message flow, пунктирні — association.
