## 1. Результати роботи

Підготовлено опис програмного продукту «СтейНау»,
дві BPMN-моделі бізнес-процесів та беклог із 12 User Stories.
Створено спільний репозиторій GitHub і розподілено
завдання відповідно до ролей учасників.

Під час завантаження BPMN-моделей виникла проблема
з розташуванням файлів. Інженер виправив структуру
репозиторію та видалив зайві копії файлів.

## 2. Start / Stop / Continue

Пропозиції для обговорення та погодження командою.

| Start — почати | Stop — припинити | Continue — продовжити |
|---|---|---|
| Перевіряти шляхи файлів перед комітом | Завантажувати файли без перевірки структури папок | Працювати у спільному репозиторії GitHub |
| Проводити перехресне рецензування артефактів | Відкладати перевірку матеріалів до дня Demo | Розподіляти завдання відповідно до ролей |
| Фіксувати неоднозначності вимог | Зберігати дублікати файлів у репозиторії | Підтримувати зв'язок між вимогами та User Stories |
